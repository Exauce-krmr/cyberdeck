# Prompts DeepAI

Le générateur DeepAI a déjà son mode cyberpunk : pas de consignes de style ici, seulement ce qu'on voit (sujet, vêtements, matières, couleurs, décor). Des détails précis évitent les images génériques.

Enregistre chaque image sous `public/img/cards/<slug>.png` (le nom du fichier est le slug). Format paysage 4:3 si le générateur le propose.

Si une image arrive avec un cadre de carte dessiné dans l'image, régénère-la en ajoutant `, no frame` à la fin : le jeu dessine déjà son propre cadre.
